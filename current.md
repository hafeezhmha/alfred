# Current

Dated log of what is being worked on, what happened, and where it stopped.
Newest entry first. The agent reads the top entry at session start and greets
you with it; it adds or updates the top entry before stopping. Keep entries
short and link to `areas/` for detail. Open loops live in `queue.md`, not here.

Entry shape:

```
## YYYY-MM-DD — <topic>
Working on: one line.
Done: bullets, each concrete.
Stopped at: the exact point, so tomorrow-you can resume with no memory of today.
Energy: low / ok / high, and anything that affected it.
Next: see queue.md.
```
